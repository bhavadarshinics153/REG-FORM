# REG-FORM

### 📝 Registration Form – HTML, CSS & JavaScript

A responsive **Registration Form** built from scratch while learning and practicing **HTML, CSS, and JavaScript**. This project helped me understand how frontend form validation, user input handling, DOM manipulation, and real-time feedback work together.

### ✨ Features

* Clean and simple registration form UI
* Real-time Name, Email & Password validation
* Password minimum-length validation
* Bio character counter with a 200-character limit
* Dynamic error messages
* Submit button enabled only when required fields are valid
* Form reset after successful submission
* Responsive design using CSS media queries
* Placeholder styling and focus effects

### 🎯 What I Learned

* HTML form structure and input elements
* CSS layout, styling, pseudo-classes and responsive design
* JavaScript DOM manipulation
* `addEventListener()` and real-time `input` events
* Form validation using JavaScript
* Regular Expressions for email validation
* Using functions and conditions to control form behaviour

This is a **self-practice project created while learning frontend development**, with the goal of strengthening my fundamentals by building the functionality on my own.
